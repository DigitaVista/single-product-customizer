== Visual Drag & Drop Page Builder for Single Product Pages ==

Create custom WooCommerce single product page layouts using a visual drag-and-drop builder.

No coding is required. Build your layout, arrange product elements, preview the result, and apply the template to your store.

* **Visual Drag & Drop Canvas** — Build product layouts visually.

== Frequently Asked Questions ==

= Can I build a WooCommerce product page without coding? =

Yes. The Visual Drag & Drop Builder lets you create and customize single product page layouts without writing code.

= Can I create multiple product page templates? =

Yes. You can create, edit, duplicate, preview, publish, draft, trash, and restore multiple templates.

= Can I use variation swatches inside the builder? =

Yes. The Add to Cart widget supports Color/Label Swatches, Variation Table/Grid, and WooCommerce Default Dropdowns.

= Can I assign different templates to different products? =

Yes. Product-specific and category-specific template assignments are available with Pro.

= Is Quick Checkout available in the Free version? =

Yes. The Free version includes Quick Checkout with the Modern Horizontal layout. Pro adds additional layouts and advanced inline checkout controls.

= Should I use the Builder or the Settings panel? =

Use the Builder when you want full control over the product page layout. Use the Settings panel for quick changes such as hiding elements, changing labels, or enabling AJAX Add to Cart.

= Does the plugin work with WooCommerce Block Themes? =

Yes. The plugin is designed to work with standard WooCommerce themes and Block Themes (FSE).

== Installation ==

1. Go to **Plugins > Add New** in your WordPress admin dashboard.
2. Search for **Product Page Customizer for WooCommerce**.
3. Click **Install Now** and then **Activate**.
4. Open **Single Product Customizer** from your WordPress admin menu.
5. Create your product page template or configure the available customization settings.
